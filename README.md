# Student Registration Management System

A web-based Student Registration Management System developed using HTML, CSS, PHP and MySQL.

## Project Description

This project allows users to manage student registration records through a simple web interface. Student information can be added, viewed, updated and deleted from the MySQL database.

## Features

- Student registration form
- Add student information
- Store student data in MySQL database
- Display registered student records
- Update student information
- Delete student records
- Simple and user-friendly interface

## Technologies Used

- HTML
- CSS
- PHP
- MySQL
- XAMPP

## CRUD Operations

This project implements basic CRUD operations:

- Create – Add new student records
- Read – View student records
- Update – Edit existing student information
- Delete – Remove student records

## Database

The project uses MySQL database for storing student registration information.

### Table Name

student1

## How to Run

1. Install XAMPP.
2. Start Apache and MySQL from XAMPP.
3. Place the project folder inside:

   xampp/htdocs/

4. Open phpMyAdmin.
5. Create the required database.
6. Create a table named:

   student1

7. Make sure the database connection details in `connect.php` are correct.
8. Open the project in a browser:

   http://localhost/student__project/
